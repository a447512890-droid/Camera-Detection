## 来源与制作方式

- 风格参考：用户提供的七麦数据页面中 App Store 宣传截图。
- 场景背景：使用内置 ImageGen 生成，要求无文字、无品牌、无水印，顶部与中央保留排版空间。
- 手机界面：从当前 `index.html` 中文原型页面确定性截取。
- 文字、序号、尺寸和组合排版：由 `source/store-artwork.html` 确定性生成，避免生成式文字错误。
- 原型集成：`index.html` 的 `store-artwork` 文档页。
